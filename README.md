# Яндекс Практикум: «Путешествия по России»

## Кратко о проекте
Это лендинг про небанальные направления для поездок по стране. Сайт нормально выглядит и на большом мониторе, и на телефоне — сам подстраивается под экран.

## Посмотреть можно тут:
https://AlekseySamoylenko.github.io/verstka_russia/

## Какие технологии использовал
HTML5 + CSS3

Флексбоксы и гриды (без них сейчас никуда)

БЭМ-нейминг — чтобы через пару недель самому понять, что где лежит

Полностью резиновая и адаптивная вёрстка

## Как организованы файлы
index.html — главная страница

blocks/ — стили, разбитые по БЭМ-блокам

images/ — все картинки проекта

vendor/ — внешние подключаемые файлы (нормализация, шрифты)

## Что здесь интересного
Вёрстка не ломается на экранах от 320px до 4K

Современные гриды и флекс — почти нет древних костылей

БЭМ не для галочки, а чтобы поддерживать код было комфортно
